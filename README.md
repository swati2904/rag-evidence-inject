# RAG evidence-present injection benchmark (TRIM)

Code and frozen artifacts for the paper *Evidence-Present Prompt Injection in Multi-Document RAG: A Trust-Role Isolation Benchmark and Defense*. The repository targets the **evidence-present** setting for indirect prompt injection: gold supporting passages are still in the candidate pool, yet the model may follow a directive embedded in a synthetic carrier-style passage. It also contains the **TRIM** (Trust-Role Isolation Middleware) defense and its content-masking variant **TRIM-mask**.

## Definitions

| Term | Meaning here |
|------|--------------|
| **Gold document** | Passage marked as supporting the reference answer for that benchmark item. |
| **Poison document** | Synthetic adversarial passage inserted into the same retrieval pool for evaluation. |
| **Evidence-present** | The gold passage remains in the pool, so the experiment targets generation under conflicting context rather than retrieval failure. |
| **TRIM-mask** | Deterministic, role-agnostic directive-span masking applied to every retrieved passage before prompt assembly (see `defense/trim.py`). |

## Setup

```bash
python -m venv .venv
# Linux/macOS:
source .venv/bin/activate
# Windows (PowerShell):
#   .\.venv\Scripts\Activate.ps1

pip install -e .
```

`pip install -e .` installs `accelerate`, which `generation/runner.py` uses with `device_map="auto"` on the `--hf-fallback` path. Large checkpoints need sufficient disk (on the order of tens of GB for 7B-class weights). Model and tokenizer names are read from `configs/pilot.yaml`. All poison text is synthetic.

## Frozen 200-question split

The exact split used for every reported number in the paper is committed as `data/test_split.json` (sha256-stamped) and is regenerated by:

```bash
python scripts/freeze_split.py
```

All runs below accept `--test-split data/test_split.json` so that re-runs evaluate on the same 200 items.

## Running experiments

**1. Retrieval sanity (BM25 top-_k_; no LLM)** &mdash; fraction of examples where the gold passage appears in the top-_k_ BM25 results on clean (poison-free) pools:

```bash
python scripts/run_clean_sanity.py --test-split data/test_split.json
```

Writes `logs/clean_sanity_summary.json` with overall and per-source recall.

**2. Main evaluation** &mdash; 200 queries &times; 5 poison ranks &times; 5 defenses = 5,000 generation rows using local Hugging Face weights for `Qwen/Qwen2.5-7B-Instruct` (greedy decoding):

```bash
python scripts/run_pilot.py --config configs/pilot.yaml \
  --test-split data/test_split.json --hf-fallback
```

Writes `logs/pilot_summary.json` (a top-level `rows` array with one record per generation call, plus an aggregate `summary` block). The OpenAI-compatible HTTP path is available as an implementation option:

```bash
export OPENAI_BASE_URL=http://127.0.0.1:8000/v1
export OPENAI_API_KEY=EMPTY
python scripts/run_pilot.py --config configs/pilot.yaml --test-split data/test_split.json
```

Dry run without an LLM:

```bash
python scripts/run_pilot.py --no-llm --max-examples 10
```

**3. Matched clean-utility control** &mdash; same defenses on poison-free pools (writes `logs/pilot_clean_summary.json`):

```bash
python scripts/run_pilot.py --config configs/pilot.yaml \
  --test-split data/test_split.json --hf-fallback --clean-control
```

**4. Clean mask-hit diagnostic** &mdash; reproduces the false-positive masking rate reported in the clean-utility table (writes `logs/clean_mask_hit_diagnostic.json`; no LLM required):

```bash
python scripts/run_clean_mask_diagnostic.py --test-split data/test_split.json
```

**5. LLM-judge validation** &mdash; stratified `n = 200` sample compared against the rule-based ASR (writes `logs/llm_judge.json`):

```bash
python scripts/run_llm_judge.py --pilot-summary logs/pilot_summary.json --n 200
```

**6. TRIM ablation** &mdash; smaller answer-hijack sweep over defenses and poison ranks {1, 3, 5}:

```bash
python scripts/run_ablation.py --subset 16 --no-llm
```

**7. LaTeX tables from logged JSON** &mdash; regenerates the paper tables on the evidence-present subset:

```bash
python scripts/export_tables.py --filter-gold-in-topk evidence
cd paper && pdflatex main.tex
```

## Public artifacts

| Path | Contents |
|------|----------|
| `data/test_split.json` | Frozen 200-question evaluation split. |
| `logs/pilot_summary.json` | Full main-run artifact: top-level `rows` array with 5,000 per-row generation records plus an aggregate `summary` block. |
| `logs/pilot_summary_aggregate.json` | GitHub-readable aggregate view of the main run; derived from `logs/pilot_summary.json`. |
| `logs/pilot_clean_summary.json` | 1,000 per-row results for the clean-utility control. |
| `logs/clean_sanity_summary.json` | BM25 retrieval recall on clean pools (200 questions). |
| `logs/clean_mask_hit_diagnostic.json` | TRIM-mask hit rate on clean pools (mask-hit diagnostic). |
| `logs/llm_judge.json` | LLM-judge labels and rule/judge agreement metrics for the stratified `n = 200` sample. |
| `paper/tables/*.tex` | LaTeX table snippets regenerated by `scripts/export_tables.py`. |

GitHub's web viewer may not render large JSON files clearly. If `logs/pilot_summary.json` appears blank in the browser, use the **Raw** button or clone the repository to inspect it locally. The full per-row logs are the top-level `rows` array inside `logs/pilot_summary.json`; each record includes the example id, attack family/template, poison rank, defense, retrieval flags, mask-hit counts, EM/F1, rule ASR, and latency. The smaller `logs/pilot_summary_aggregate.json` file exposes the headline 5,000-row summary, evidence-present counts, per-defense metrics, per-rank metrics, per-template metrics, and bootstrap settings directly in the browser.

## Repository layout

| Path | Purpose |
|------|---------|
| `benchmark/datasets.py` | Load evaluation slices (KILT NQ, HotpotQA-style rows). |
| `benchmark/corpus_builder.py` | Build per-question document pools (gold, distractors, poison) and ranks. |
| `benchmark/templates.py` | Nine synthetic poison templates across three carrier-genre clusters. |

| `evaluation/` | EM/F1, rule-based ASR, JSONL run logging, clustered bootstrap CIs. |
| `scripts/` | CLI entry points wired to `configs/*.yaml`. |
| `configs/` | `pilot.yaml`, `main_experiment.yaml`. |
| `paper/` | LaTeX article source; table snippets under `paper/tables/`. |
| `tests/` | Regression tests, including the TRIM-mask non-oracle test. |
| `load_config.py` | YAML loader with `${VAR:-default}` substitution. |

## Natural Questions (KILT)

KILT NQ rows often provide identifiers without full Wikipedia paragraph text. `benchmark/datasets.py` can build **short surrogate passages** from metadata so retrieval and poisoning run end to end. For experiments that need full gold passage text, swap in a corpus that stores passages explicitly (e.g. a Wikipedia join).

## Ethics

The poison passages in this repository are synthetic and exist only to make controlled evaluation reproducible. TRIM-mask is intended to mitigate, not enable, indirect prompt injection. No deployed system is attacked. The released artifacts do not contain real-world prompt payloads, secrets, private data, or content from deployed systems.
